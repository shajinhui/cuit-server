# 安卓登录排查

日期：2026-10-08。用户反馈安卓登录持续失败；尚未收到手机显示的具体错误，也未连接该设备，因此目前不能认定根因。

## 已确认的情况

- 最新 APK 含 `android.permission.INTERNET`，默认使用 `https://api.fanxiaogao05.dpdns.org`。
- 从本机使用 curl 和 Dart 原生 HTTP 客户端请求会话接口，均返回 HTTP 200，内容为未登录状态。以空 JSON 请求登录接口返回 HTTP 400 与“请输入学号和密码”，没有提交真实账号。
- 这些检查说明服务从本机可达，不证明安卓手机的网络、证书或系统安全存储正常，也不代表真实账号登录已验收。

## 已修正的客户端问题

| 原行为 | 修正后的行为 |
| --- | --- |
| 连接、发送、接收超时与证书错误均显示同一条网络错误 | 分别显示超时阶段或证书校验提示，保留正常证书验证 |
| Cookie 读取或保存失败被当成断网 | 使用独立的存储错误类型与明确中文提示；恢复会话时不因此进入离线登录 |
| HTTP 401 一律显示登录过期 | 优先保留服务端给出的错误，例如学号或密码错误；无有效错误文字时才用默认提示 |
| 登录失败后的清理异常覆盖原始错误 | 尝试清理并保留原始登录失败原因；登录前仍会清理旧会话 |
| 登录前安全存储异常只显示登录未完成 | 明确提示本机登录状态读写失败，尚未完成清理时不发送凭证 |

错误提示不包含密码、Cookie、请求正文或底层平台异常。没有修改接口地址、自动重试登录、忽略证书或延长超时；这些需要根据手机上的实际错误判断。
