# 成信友友 Web

`apps/web` 是“成信友友”的 PWA 前端目录。

当前已经完成可运行的移动端页面、成绩查询流程、PWA 构建和最近一次课表离线查看。

开发或修改前端代码前，请先阅读：

- [前端开发规范](./DEVELOPMENT.md)
- [UI 设计规范](./UI_DESIGN_GUIDELINES.md)

## 计划技术栈

- Vue 3
- TypeScript
- Vite
- Vue Router
- Pinia
- vite-plugin-pwa

## 当前页面

- 登录：按设计稿实现，接入教务登录并统一维护前端登录态。
- 课表：按设计稿实现，已接入学期、个人课表和当前教学周接口，支持切换教学周、学期及添加本机手动课程；已有本机课表时不自动查询教务系统。
- 校园工具：按设计稿实现；“查空教室”、“考场查询”、“查成绩”、“校历”和“校园地图”已接入，其他入口显示未接入提示。
- 查空教室：支持学期、教学周、星期、节次、校区、教学楼、教室类型和容量筛选，结果按教学楼分组；首次查询会按学期和校区保存完整占用快照，后续筛选在本地完成。
- 考场查询：按学期动态读取考试批次并自动加载考场安排，按日期分组展示时间、课程、地点、状态和备注。
- 校历：根据当前日期计算学年并读取教务处公开校历图片，支持适应屏幕和放大查看。
- 校园地图：内置航空港与龙泉校区手绘地图，支持校区切换、分级缩放、轻点图片全屏查看、双指缩放、横屏布局和调用系统分享面板保存图片。
- 我的：读取真实学籍信息，提供学业完成情况入口和退出教务操作。
- 学业完成情况：读取培养方案预审摘要、学分进度、审核结果、要求分类和课程明细。
- 查成绩：调用 Hertz API 完成教务登录、学期读取和指定学期成绩查询。

## 目录职责

```text
apps/web/
├── public/
│   └── icons/       # PWA 图标
└── src/
    ├── app/         # 根组件、主导航、路由和跨功能生命周期编排
    ├── assets/      # 图片等静态资源
    ├── features/    # 按业务域组织 API、状态、缓存、模型和组件
    ├── pages/       # 登录、课表、工具、成绩和个人中心路由页面
    ├── shared/      # 通用请求、公共模型、composable 和基础 UI
    ├── styles/      # 全局样式
    └── main.ts      # Vite 应用入口
```

## 本地运行

先在仓库根目录启动 API：

```bash
go run ./apps/api
```

再启动前端：

```bash
cd apps/web
pnpm install
pnpm dev
```

如需修改开发代理目标，复制 `.env.example` 为本地 `.env` 并设置 `VITE_DEV_API_TARGET`。

正式环境由 Cloudflare Pages 构建时设置：

```text
VITE_API_BASE_URL=https://api.fanxiaogao05.dpdns.org
```

完整 Pages 配置见 [`deploy/README.md`](../../deploy/README.md)。

提交前执行：

```bash
pnpm run check
```

`check` 会依次运行 ESLint、单元测试、TypeScript 类型检查和生产构建。GitHub Actions 的
`.github/workflows/web.yml` 会在前端文件发生 push 或 pull request 时执行相同检查。

业务测试与对应源码放在同一目录，当前覆盖课表、空教室、成绩模型和会话状态流转。
课表、空教室、成绩和会话功能只通过各自的 `index.ts` 向应用层和页面暴露能力，功能内部使用相对路径引用自己的实现。

## iPhone / iPad 安装

正式环境应通过 HTTPS 提供页面。在 Safari 中打开页面后，依次选择“分享”→“添加到主屏幕”，并保持“打开为 Web App”开启。

Safari 不支持网页调用 `beforeinstallprompt`。应用会在课表、工具或个人中心显示自己的安装提示，点击“安装方法”后展示上述分享菜单步骤；个人中心也始终保留安装入口。应用通过 `display-mode` 和 `navigator.standalone` 判断是否已从主屏幕启动，已安装时不会继续提示。

如果设备上已经安装过旧版主屏幕书签，需要先删除旧图标再重新添加，Safari 才会读取新的独立显示模式和 CUIT 应用图标。

## Android 安装

正式环境同样必须通过 HTTPS 提供页面。Chrome、Edge、Opera、三星浏览器以及支持
`beforeinstallprompt` 的国产 Chromium 浏览器在确认应用可安装后，会在课表、工具或个人中心显示安装提示；用户点击“安装”后才会调用浏览器的系统安装确认框。

个人中心始终提供“安装到桌面”入口。浏览器不能主动弹出系统安装框时，该入口会显示当前浏览器对应的手动安装步骤；微信、QQ、钉钉等应用内浏览器会先提示用户改用系统浏览器打开。用户关闭自动提示后，14 天内不会再次自动显示，个人中心入口不受影响。

## 安全边界

前端只访问本项目后端 API，不直接访问 CAS 或 EAMS，不保存教务密码、CAS Ticket 或学校系统 Cookie。“保持登录状态”只延长后端随机会话 Cookie 的有效期。

Service Worker 只预缓存前端静态资源，不缓存 `/api` 响应。最近一次成功读取的学期、课表、当前教学周、用户手动添加的课程，以及按学期和校区划分的教室占用快照由前端写入 IndexedDB。课表和空教室已有对应本机数据时优先读取缓存，仅首次无缓存、用户主动更新或切换到未缓存的学期/校区时查询远端。成绩和登录、退出、鉴权响应不进入离线缓存。主动退出、确认未登录、收到 401 或新账号登录成功时会清除旧课表、手动课程和教室占用快照。
