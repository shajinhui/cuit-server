# 成信友友 Web UI 设计规范

本文档定义 `apps/web` 的长期视觉与交互标准。新增页面、修改组件、替换图标或调整动画时均应遵守。

本项目采用“克制的 iOS 风格”，目标是清晰、安静、可靠，而不是机械复刻系统界面。应优先保证信息层级、触控反馈、平台一致性和可访问性，再考虑装饰效果。

## 1. 设计原则

1. **灰色为基础**：常规页面使用浅灰背景和白色分组卡，不使用绿色作为品牌色或主操作色。
2. **颜色表达语义**：蓝色只表示主操作、焦点和选中态；红色只表示危险或退出操作。
3. **内容优先**：层级主要依靠字号、字重、间距和分组建立，不依赖大阴影、渐变或高饱和色。
4. **即时反馈**：可点击元素在按下时立即反馈，不等待请求结束后才发生视觉变化。
5. **动效有目的**：只为反馈、状态变化或空间关系添加动画；频繁操作应短促或不动画。
6. **统一胜过个性**：相同外观必须有相同行为；页面不得各自发明按钮、圆角、颜色和动效。
7. **移动端优先**：以单手触控和安全区为基础，同时支持 320–480px 宽度。

## 2. 颜色

### 2.1 基础色板

以下色值是新 UI 的标准语义。新增公共变量时使用这些名称，避免继续增加意义重复的颜色。

```css
:root {
  --ios-accent: #0088ff;
  --ios-danger: #ff383c;

  --ios-label: #1c1c1e;
  --ios-secondary-label: #636366;
  --ios-tertiary-label: #8e8e93;

  --ios-icon-primary: #1c1c1e;
  --ios-icon-secondary: #8e8e93;
  --ios-icon-disabled: #c7c7cc;

  --ios-control-background: #e5e5ea;
  --ios-control-pressed: #d1d1d6;
  --ios-page-background: #f2f2f7;
  --ios-surface: rgba(255, 255, 255, 0.94);
  --ios-separator: rgba(60, 60, 67, 0.18);

  --ease-out: cubic-bezier(0.23, 1, 0.32, 1);
}
```

### 2.2 使用规则

| 场景 | 颜色 | 规则 |
| --- | --- | --- |
| 页面背景 | `#F2F2F7` | 工具、我的及其他分组式页面统一使用 |
| 主文字、主要图标 | `#1C1C1E` | 标题、正文、未选中主导航图标 |
| 次要文字 | `#636366` | 说明、正文辅助信息 |
| 弱化文字、次要图标 | `#8E8E93` | 时间、学号、占位、箭头 |
| 禁用状态 | `#C7C7CC` | 禁用图标和低优先级状态 |
| 中性控件 | `#E5E5EA` | 头像底、图标底、灰色按钮 |
| 按下状态 | `#D1D1D6` 或 10% 黑色 | 触摸反馈，不作为常驻背景 |
| 主操作、选中态 | `#0088FF` | 主按钮、焦点、当前导航 |
| 危险操作 | `#FF383C` | 退出、删除；不得用于普通提示 |

补充约束：

- 不使用绿色作为页面主色、按钮色、开关色或装饰性渐变。
- 蓝色不用于普通说明文字，避免页面到处出现“可点击感”。
- 危险操作除颜色外必须有明确文字，不能只靠红色表达。
- 课表属于信息可视化，可以使用稳定的课程颜色；非本周课程固定使用 `#D1D1D6` 背景和 `#636366` 文字。
- 页面主题色必须与页面背景一致，统一通过 `usePageTheme()` 设置安全区颜色。

## 3. 排版

全局使用现有系统字体栈。页面内不得单独设置其他字体，也不引入仅用于装饰的 Web Font。

| 层级 | 建议值 | 用途 |
| --- | --- | --- |
| 页面主标题 | 28px / 700 / 1.08 | 姓名、核心页面标题 |
| 区块标题 | 20–22px / 650 | 页面中的一级分组 |
| 列表主文字 | 17px / 560–650 / 1.25 | 分组列表、主要操作 |
| 正文 | 15–16px / 400–500 / 1.45 | 说明与普通内容 |
| 辅助文字 | 13–14px / 400–500 / 1.35 | 学号、地点、状态 |
| 底部导航 | 12px / 600 / 1.15 | 主导航标签 |

规则：

- 24px 以上标题可使用 `letter-spacing: -0.02em`；正文保持正常字距。
- 不通过堆叠多个大号粗体制造层级。
- 同一列表行最多保留一个主要标题和一行辅助文字。
- 长文本应换行或省略，但错误信息不得被笼统文案完全隐藏。

## 4. 间距与布局

使用以下间距序列：

```text
4 / 8 / 12 / 16 / 20 / 24 / 32
```

核心尺寸：

| 项目 | 标准 |
| --- | --- |
| 页面最大宽度 | 480px |
| 页面水平边距 | 22px；≤370px 时可降至 16px |
| 页面区块间距 | 24px |
| 列表行高度 | 60–68px |
| 最小触摸目标 | 44×44px |
| 内容底部预留 | `84px + env(safe-area-inset-bottom)` |
| 视觉验收基准 | 390×844px |

页面必须：

- 使用 `100dvh`，同时保留 `100vh` 回退。
- 通过 `env(safe-area-inset-top)` 和 `env(safe-area-inset-bottom)` 适配刘海与主屏幕模式。
- 在 320px 宽度下不出现横向滚动。
- 保持内容自然向下排列，不用绝对定位拼出主要页面结构。

## 5. 圆角、表面与阴影

### 5.1 圆角

| 组件 | 圆角 |
| --- | --- |
| 白色分组卡 | 22–24px |
| 分组内图标底 | 10–12px |
| 输入框、普通控件 | 12–16px |
| 独立胶囊按钮 | 高度的一半 |
| 底部导航外层 | 32px |
| 底部导航选中层 | 27px |
| 头像 | 50% |

嵌套圆角必须有几何关系。外层和内层胶囊应使用同一圆形端部逻辑，不能出现一层很圆、另一层明显偏方的情况。

### 5.2 表面

- 分组式页面使用 `#F2F2F7` 背景和接近纯白的卡片。
- 平坦背景上的大卡片不使用重毛玻璃；它只会让白色变脏。
- 毛玻璃只用于悬浮导航、工具栏、抽屉等真正覆盖内容的功能层。
- 不在毛玻璃上继续叠加另一层浅色毛玻璃。

### 5.3 阴影

- 分组卡默认无阴影或仅使用极轻的 0.5px 深度。
- 悬浮底部导航可以使用较深阴影表达悬浮层级。
- 不同时使用厚边框、强阴影和高模糊；一个表面只需要一种主要分隔方式。

## 6. 图标

1. 优先复用 `src/assets/icons/` 中现有资源。
2. 导航图标使用 CSS mask + `currentColor`，避免为选中态重复加载图片。
3. 不混用 Emoji、不同线宽的 SVG 和写实图片作为同级功能图标。
4. 图标必须与功能语义一致，例如退出不能使用学士帽图标。
5. 装饰性图标使用 `alt=""` 或 `aria-hidden="true"`；纯图标按钮必须提供 `aria-label`。

标准尺寸：

| 场景 | 尺寸 |
| --- | --- |
| 行尾箭头 | 18px |
| 普通列表图标 | 24px |
| 导航图标 | 30px |
| 分组列表图标底 | 34–36px |

图标颜色遵守：

- 主要：`#1C1C1E`
- 次要：`#8E8E93`
- 禁用：`#C7C7CC`
- 选中：`#0088FF`
- 危险：`#FF383C`

## 7. 组件规范

### 7.1 白色分组列表

- 背景：`rgba(255, 255, 255, 0.94)`
- 圆角：22px
- 行高：64px 左右
- 分隔线：0.5px，颜色使用 `--ios-separator`
- 分隔线从文字列开始，不贯穿左侧图标区
- 图标、标题、辅助文字和箭头必须在所有行中对齐
- 按下时立即显示约 10% 的灰色背景

### 7.2 按钮

| 类型 | 样式 |
| --- | --- |
| 主按钮 | 蓝色背景或蓝色主文字，只用于页面主要动作 |
| 中性按钮 | `#E5E5EA` 背景，深色文字 |
| 危险按钮 | 红色文字或红色背景，与普通操作分组隔离 |
| 图标按钮 | 至少 44×44px，图标通常为 20–24px |

独立按钮按下时可使用 `scale(0.97)`；分组列表行优先使用背景色反馈，避免缩放后露出边缘缝隙。

### 7.3 输入框

- 输入区域高度至少 52px。
- 标签、输入值和错误提示有明确层级。
- 聚焦态使用蓝色焦点环，不通过绿色描边表达。
- 密码显示按钮、开关和清除按钮均需满足 44px 触摸目标。
- 禁止只用 placeholder 代替可访问的 label。

### 7.4 底部导航

底部导航是唯一默认使用毛玻璃的全局组件：

- 外层宽度：`calc(100% - 56px)`，最大 396px
- 最小高度：64px
- 内边距：5px
- 外层圆角：32px
- 选中层圆角：27px
- 图标：30px
- 文字：12px / 600
- 选中层移动：180ms `--ease-out`

导航图标组件必须稳定挂载。切换页面时只移动选中层和更新颜色，不能通过更换节点导致所有图标闪烁或重新出现。

### 7.5 Toast 与状态

- Toast 出现 180ms，消失 120ms；消失应比出现更快。
- Toast 只承载短反馈，不显示需要用户仔细阅读的错误详情。
- 加载、错误、空数据、离线和成功状态必须分别设计。
- 加载时保留已有内容，避免刷新动作把页面突然清空。
- 错误重试按钮至少 44px 高，并保留后端可安全展示的具体错误信息。

## 8. 动效

动效必须先回答“它在解释什么”。

### 8.1 推荐时长

| 交互 | 时长 |
| --- | --- |
| 按压反馈 | 100–160ms |
| 小型浮层、Tooltip | 125–200ms |
| 导航选中层 | 180ms |
| Toast 出现 / 消失 | 180ms / 120ms |
| 弹窗、抽屉 | 220–300ms |

规则：

- UI 动画一般不超过 300ms。
- 进入和退出沿同一路径，退出应更快。
- 普通 UI 使用 `--ease-out`；屏幕内位置变化使用强 `ease-in-out`。
- 只动画 `transform`、`opacity`，必要时动画颜色。
- 禁止 `transition: all`、`ease-in`、从 `scale(0)` 出现。
- 高频导航、键盘操作和数据阅读不添加装饰性入场动画。
- 手势驱动的抽屉或拖拽必须可中断，并从当前屏幕位置继续。

### 8.2 减少动态效果

所有新增动画必须提供 `prefers-reduced-motion` 方案：

- 移除位移、弹跳和大面积缩放。
- 保留有助理解的短暂透明度或颜色变化。
- 不得因为关闭动画而失去按压、加载或完成反馈。

## 9. 可访问性

- 使用语义化 `button`、`a`、`label`、`nav` 和标题层级。
- 点击区域不小于 44×44px。
- 键盘焦点必须可见，并使用与页面主操作一致的蓝色焦点环。
- 信息不得只靠颜色传达；危险、错误和选中状态都需要文字或形状辅助。
- 动态状态使用 `role="status"`、`aria-live` 或 `role="alert"`。
- 支持 `prefers-reduced-motion`、`prefers-reduced-transparency` 和 `prefers-contrast`。
- 正文和辅助文字需要验证对比度；透明背景上的文字应适当提高不透明度和字重。
- 用户隐私信息默认脱敏，完整敏感信息不得直接出现在截图、日志或 URL 中。

## 10. 页面主题与安全区

页面组件统一调用：

```ts
usePageTheme('#f2f2f7')
```

同时保证对应页面 Shell 使用相同背景：

```css
.app-shell.app-shell--example {
  background: #f2f2f7;
}
```

规则：

- 页面背景、`html`、`body` 和 `<meta name="theme-color">` 必须一致。
- 不在页面内重复手写主题恢复逻辑。
- 课表等需要专用画布色的页面可以例外，但 Shell 与 `usePageTheme()` 必须使用同一色值。

## 11. 响应式与验收

每次涉及 UI 的修改至少检查：

1. 390×844px：主要视觉验收尺寸。
2. 360px 宽度：窄屏文字和卡片内边距。
3. 430px 宽度：大屏手机的留白与最大宽度。
4. `scrollWidth === clientWidth`：无横向溢出。
5. 页面顶部、底部与 PWA 安全区颜色连续。
6. 底部导航不遮挡最后一个操作。
7. 浏览器控制台无新增 warning/error。

修改完成后在 `apps/web` 运行：

```bash
pnpm run check
```

## 12. 实现位置

| 内容 | 位置 |
| --- | --- |
| 全局字体、焦点、通用卡片、Toast | `src/styles/main.css` |
| 页面样式 | `src/styles/<page>.css` |
| 主导航 | `src/app/components/BottomNavigation.vue` |
| 页面外壳 | `src/shared/ui/AppShell.vue` |
| 页面主题与安全区 | `src/shared/composables/usePageTheme.ts` |
| 图标资源 | `src/assets/icons/` |

页面专属样式必须使用页面前缀，例如 `.profile-*`、`.tools-*`，避免无作用域选择器影响其他页面。

## 13. 设计评审清单

- [ ] 页面是否使用正确的背景色和 `usePageTheme()`？
- [ ] 蓝色、红色是否只用于对应语义？
- [ ] 是否新增了绿色主操作或无意义的高饱和色？
- [ ] 信息层级能否仅靠标题、正文和辅助文字理解？
- [ ] 同级卡片、行高、圆角、图标尺寸是否一致？
- [ ] 图标语义是否正确，是否混入 Emoji 或不同风格资源？
- [ ] 触摸目标是否至少 44px？
- [ ] 按下时是否立即反馈？
- [ ] 是否存在 `transition: all`、`ease-in` 或超过 300ms 的常用动画？
- [ ] 是否支持减少动态效果、减少透明度和高对比度？
- [ ] 是否验证 390×844、窄屏、安全区和横向溢出？
- [ ] 是否运行 `pnpm run check`？
