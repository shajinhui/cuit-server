# 共享校历数据

本目录只保存学校公开校历的事实配置，不保存个人数据。Go 通过 `go:embed` 将 JSON 编入 API 二进制，Web 在构建时导入同一个 JSON；不新增接口或运行时配置文件，离线日期换算不依赖学校网站。

## 日期来源

| 学年 | 第一学期第一周周一 | 第二学期第一周周一 | 每学期周数 | 官方校历 |
| --- | --- | --- | --- | --- |
| 2024–2025 | 2024-09-02 | 2025-02-24 | 20 / 20 | [校历](https://jwc.cuit.edu.cn/xl2024_2025.png) |
| 2025–2026 | 2025-09-08 | 2026-03-02 | 20 / 20 | [校历](https://jwc.cuit.edu.cn/xl2025_2026.png) |
| 2026–2027 | 2026-09-07 | 2027-02-22 | 19 / 19 | [校历](https://jwc.cuit.edu.cn/xl2026_2027.png) |

`firstWeekMonday` 指校历上**标为第一周的周一**，不是报到日，也不一定是正式上课第一天。例如 2026–2027 秋季 9 月 5 日报到，但第一周从 9 月 7 日开始；2025–2026 春季正式行课从 3 月 5 日开始，第一周周一仍是 3 月 2 日。

周一至周日属于同一教学周；当前日期在已配置教学周期之外返回 0。页面浏览第 N 周时按该学期第一周顺推，不从今天或缓存中的旧当前周倒推。尚未核实的学期显示“校历待更新”，仍可按周次查看课程，但不展示猜测的月日。

## 作息与校区

[学校通知](https://jwc.cuit.edu.cn/info/1172/3679.htm)及[新作息表](https://jwc.cuit.edu.cn/zxsjb269.pdf)规定：自 2026–2027 第一学期起，两校区统一作息。课表模型根据**所选学期**应用该规则：历史学期的龙泉校区前两节为 08:30–09:15、09:25–10:10；其他情况使用新表。校区来自个人信息接口 `Campus`，优先读本机缓存；校区缺失时默认航空港，待信息读入自动更新。

## 后续维护

1. 核实学校新校历，按第一周标记填写日期、周数与来源，禁止套用“九月一日所在周”或“三月第一个周一”。
2. 更新 `calendars.json` 并补充周一、周日、假期和跨年回归样例。Web/Android CI 已包含本目录变更。
3. 执行 `go test ./...`、`go vet ./...` 和 `apps/web` 下的 `pnpm run check`。
4. 发布前端资源并重新构建部署 API；若更正已上线的日期计算，递增当前周 Redis Key 版本，防止当天旧缓存覆盖修正。

本次当前周缓存 Key 升为 `cuit:v3:current-week`，无须删除用户课表、手动课程或个人信息缓存。
